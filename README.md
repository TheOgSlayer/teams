# JalebiScoreboard

Sidebar scoreboard for JALEBI SMP (Paper 1.21.7+, Vault for money).

- `/scoreboard` (`/sb`) opens a dialog to toggle: scoreboard, name, money, kills, deaths, playtime, team
- `/team` (aliases `/teams`, `/jteam`) opens the Jalebi Teams dialog; also `/team home|sethome|invite <player>|leave`

## Build
Push to GitHub, then open the **Actions** tab, pick the latest run and download the
`JalebiScoreboard` artifact. Or locally: `mvn package` (Java 21).
